# สิ่งสำคัญที่สุด: แบ่งระบบเป็น 3 ชั้น

ถ้าต้องอธิบายให้เพื่อนเข้าใจง่าย ผมจะไม่เอา 9 ชั้นด้านบนไปพูดทั้งหมด แต่แบ่งเป็น:

## ① HARDWARE

```text
AWR1843BOOST
     ↓
Radar Data

Ground Truth:
sEMG
IMU
Force
Camera

Computer:
Notebook → Development
Raspberry Pi → Final Edge
```

Radar เป็น **Sensor หลัก** ส่วน sEMG/IMU/Force/Camera เป็น **เครื่องมืออ้างอิงตอนพัฒนาและ Validate** ไม่ใช่สิ่งที่ผู้ป่วยต้องใส่ทั้งหมดในระบบสุดท้าย ซึ่งตรงกับ Proposal ที่ระบุว่า sEMG และ IMU ใช้เป็น reference/validation และ prototype สุดท้ายมุ่งไปที่ Radar เพียงตัวเดียว :chatgpt-content-reference{index="1"}

```text
 Model       Model         Model         │

└────────────┴────────────┴──────────────┘
```

Proposal ระบุ Signal Processing ที่จะพิจารณา เช่น Range FFT, Doppler FFT, Micro-Doppler, Spectrogram และ Motion Trajectory รวมถึง candidate AI เช่น CNN, CNN-LSTM, LSTM, TCN และ Transformer :chatgpt-content-reference{index="2"}

**ยังไม่ควรล็อกว่า Fatigue Model ต้องเป็น XGBoost หรือ LSTM** เพราะ Proposal เองยังเปิดให้เลือก Model ตามข้อมูลจริงและผลการทดลอง

# แล้ว Ground Truth อยู่ตรงไหน?

นี่เป็นจุดที่อยากให้ทีมเข้าใจตรงกันที่สุด:

**Ground Truth ไม่ได้อยู่ใน Final Product**

มันเป็น **Development & Validation Layer**

```text
                 RADAR

             Radar Features

       │                       │
       ▼                       ▼
    AI Model              Ground Truth
```


### Movement


# Development Roadmap

ผมจะใช้ **7 Phase ของ Proposal เป็น Project Management Structure** เลยครับ:

| Phase | ทำอะไร | Hardware หลัก |
|---|---|---|
| **1. Proof of Concept** | ตรวจจับ Elbow Flexion / Gross Movement | AWR1843 + Notebook |
| **2. Muscle Signal Investigation** | หา Radar Feature ที่สัมพันธ์กับ Fatigue | Radar + sEMG/Force/IMU |
| **3. Compensation Detection** | ตรวจ Shoulder / Trunk Compensation | Radar + Phone/IMU |
| **4. Signal Fusion** | รวม Muscle State + Movement State | Radar + AI |
| **5. Temporal Prediction** | Fatigue → Compensation Prediction | AI Computer |
| **6. Personalization** | สร้าง Personal Signature | AI + Historical Data |
| **7. Demonstration System** | Real-time Dashboard | Radar + Raspberry Pi + Phone |

ลำดับนี้ตรงกับ Phase 1–7 ใน Proposal โดยตรง :chatgpt-content-reference{index="7"}
