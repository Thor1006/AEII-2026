# Plan: Home page (product landing page)

**Status:** done
**Date:** 2026-10-12

## Why
The dashboard opens straight on a "Connect your kit" screen. There is nothing to show first when presenting TrueRehab-RF. The user wants a product-landing-style home page with a hero and a live demo preview, in English.

## Approach
1. **Routing, no library:** a tiny hash route in `App.tsx`: `#/` shows Home, `#/app` shows the dashboard (the current start screen and views). "Open dashboard" and "Try the demo" go to `#/app`.
2. **Hero:** logo, one-line promise (draft: "See the recovery. Spot the compensation."), a short sub-line (contactless radar, no cameras or wearables), and two buttons: **Try the demo** (primary, starts `MockSource`) and **Connect a kit** (secondary, goes to the connect screen).
3. **Live demo preview:** one floating panel below the hero, showing the three scores (fatigue, movement quality, compensation) and a small trend, fed by the built-in demo source. Clearly labelled "Demo data, not a measurement".
4. **Style:** reuse existing tokens only (floating cards, 16px/10px radii, mono accent, Inter, no gradients). Responsive down to phone width. Light and dark.
5. **Copy:** English, plain words, no medical claims (supports physiotherapists, doesn't replace them).

## Files touched
- `frontend/src/home/Home.tsx`, `Home.module.css` — new page.
- `frontend/src/App.tsx` — hash route; keep the dashboard unchanged under `#/app`.
- Possibly `frontend/src/widgets/` — reuse `ScoreGauge` / `ScoreTrendWidget`; no changes expected.

## Risks / needs OK
- The preview needs its own demo data feed. If the sensor context can't host two sources, the preview becomes a looping canned animation instead of live widgets. I'll check first and tell you which.
- The tagline and copy are drafts. You decide the final wording.
- Not in scope (you didn't pick them): problem section, how-it-works section, Thai text. Easy to add later.

## How we'll verify
- `npm run typecheck` and `npm run build`.
- Browser pane: `#/` and `#/app` in light and dark, at phone and desktop width; both buttons work; no console errors.
