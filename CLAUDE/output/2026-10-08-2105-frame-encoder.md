# Report: CNN frame encoder v0.1

**Date:** 2026-10-08 21:05 · **Result:** ✅ done · **Plan:** [2026-10-08-frame-encoder.md](../plans/2026-10-08-frame-encoder.md)

## Goal
Build the reusable CNN frame encoder that `plans/radar_ml_context.md` asks for, with an input definition that can change, in `sandbox/Encoder_0.1/`.

## What changed
- `sandbox/Encoder_0.1/frame_encoder.py`: `InputContract`, `FrameEncoderConfig`, `FrameEncoder`. Input `[B,C,H,W]` gives `[B,E]`; `encode_sequence` turns `[B,T,C,H,W]` into `[B,T,E]`. GroupNorm by default. An axis is only pooled while it stays ≥ `min_size`. `save` and `load` handle the weights, config and contract together, and loading refuses a mismatch.
- `sandbox/Encoder_0.1/check_encoder.py`: 17 sanity checks.
- `sandbox/Encoder_0.1/encoder_probe.py`: the encoder plus a linear head, run on the simulated compensation task from `ml_example.py`, compared with `SmallCNN`. `ml_example.py` was not edited.
- `sandbox/Encoder_0.1/README.md`: the input definition, the architecture, the results, and open items.
- `CLAUDE/plans/2026-10-08-frame-encoder.md`: new plan, now marked done.

## Verified by
- `python3 sandbox/Encoder_0.1/check_encoder.py` → **17/17 pass**. Details:
  - 113,904 params
  - CPU vs MPS max difference 6e-7
  - forward+backward for a batch of 32 at 128×64: CPU 51 ms, MPS 4.6 ms
  - overfits 8 random samples (loss 0.0002)
  - save/load gives identical outputs
- `python3 sandbox/Encoder_0.1/encoder_probe.py`, LOSO macro-F1 on **synthetic** data:

| Model | Macro-F1 |
|---|---|
| majority | 0.17 |
| SmallCNN | 0.58 ± 0.08 |
| encoder | 0.59 ± 0.06 |

  Both get trunk lean 64/64, and both confuse shoulder elevation with correct form.

## Issues / not done
- The tie is expected: simulated shoulder elevation barely shows up in range or Doppler (a known sandbox finding). The fix is in the sensing setup, not model size.
- Defaults (1 channel, E=128) are guesses until there is a real AWR1843 config. A Phase 2 micro-vibration signal may need a 1D branch.
- Not built: temporal attention, real heads, calibration, live capture, the oversized-model experiment.
